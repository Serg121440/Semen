# Travel Deals Monitor Bot

MVP Telegram-бота для поиска коротких городских поездок из Москвы. В проекте есть Telegram-команды, FastAPI, PostgreSQL, Redis-контейнер, дедупликация, Travel Score и распознавание предложений из сообщений каналов.

## Быстрый запуск

1. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN` от BotFather.
2. Запустите `docker compose up --build`.
3. Откройте `http://localhost:8000/docs`; в Telegram отправьте боту `/start`, затем `/scan`.

Без токена приложение стартует в API-only режиме. Демонстрационный источник включён по умолчанию и позволяет проверить полный путь `/scan` без коммерческих API.

## Что уже работает

- `/start`, `/scan`, `/settings`, `/countries`, `/history`, `/favorites`, `/help`;
- единая модель предложений от туроператоров, авиапоиска и Telegram;
- скоринг 0–100, суперцена при скидке от рынка не менее 30%;
- дедупликация предложений;
- добавление и удаление источников через `/admin/sources`;
- изменение пользовательских параметров через `PATCH /users/{telegram_id}`;
- ежедневный персонализированный поиск и доставка новых предложений;
- PostgreSQL и Redis в Docker Compose;
- базовые тесты скоринга и извлечения Telegram-сообщений.

## Подключение реальных источников

Реализуйте интерфейс `DealSource` из `app/parser/base.py` для каждого официального/партнёрского API и добавьте экземпляр в `app/main.py`. Для Travelata, Level.Travel, OnlineTours, Sletat.ru, Aviasales и Яндекс Путешествий потребуются выданные ими ключи и соблюдение партнёрских условий. Telegram-каналы следует читать через отдельную пользовательскую MTProto-сессию (например, Telethon), а Bot API не даёт боту произвольно читать чужие каналы.

Перед публичным запуском добавьте авторизацию admin API, Alembic-миграции вместо `create_all`, фоновые ежедневные/еженедельные задачи, реальное хранение календарных ограничений и кнопки редактирования настроек.
