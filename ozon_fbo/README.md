# Ozon FBO — планирование поставок (Google Apps Script)

`Code.gs` вставляется в редактор Apps Script таблицы Google
(Расширения → Apps Script), целиком вместо старого кода.

## Настройки (лист «Поставка FBO»)

| Ячейка | Что это |
|---|---|
| B2 | Client-Id |
| B3 | API-ключ Seller API |
| B5 | Период продаж, дней (последние полные дни) |
| B6 | Целевой запас, дней |
| B7 | Коэффициент продаж |

## Расчёт

```
продажи        = продажи за B5 дней × B7
продажи в день = продажи / B5
рекомендация   = продажи в день × B6 − остаток − в пути  (с округлением по типу товара)
дней запаса    = (остаток + в пути) / продажи в день
```

Одна формула используется на основном листе и в кластерной таблице.

## Ручные правки

Значения в «Поставить» (лист «Поставка FBO») и «План» (лист «Продажи по
кластерам») можно менять вручную. Такая ячейка становится оранжевой и
не перезаписывается при обновлении. Чтобы вернуть авторасчёт, очистите
ячейку или выберите «Ozon FBO → Сервис → Сбросить ручные правки плана».

## Проверка

```
node ozon_fbo/tests/harness.test.js
```

Тест прогоняет создание таблиц, обновление, ручные правки, сборку плана
и сопоставление складов на имитации Google Sheets и Ozon API.
